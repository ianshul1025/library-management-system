# 📚 Library Management System

A production-ready **Library Management System** built using the **MERN Stack**.

This project is being developed as a collaborative team project following industry-standard Git workflows, modular architecture, and clean coding practices.

---

# 🚀 Tech Stack

## Frontend

- React.js
- Vite
- React Router
- Tailwind CSS v4
- Axios

## Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt

# ⚙️ Setup Instructions

## 1. Clone Repository

```bash
git clone https://github.com/ianshul1025/library-management-system.git
```

---

## 2. Install Backend

```bash
cd backend
npm install
```

Run:

```bash
npm run dev
```

---

## 3. Install Frontend

```bash
cd frontend
npm install
```

Run:

```bash
npm run dev
```
